Rappel de sauvegarde

Sauvegarde dans Fichiers

Tout est inclus : clientes, rendez-vous, paiements, suppléments, repères, événements personnels, dépenses et réglages. Sur iPhone, choisis ensuite « Enregistrer dans Fichiers » et le dossier souhaité. Ne place jamais ce fichier dans ton dépôt GitHub public.

Mon agenda

Application personnelle hors ligne. Les données sont enregistrées dans une base locale contrôlée avant chaque ouverture et ne sont pas envoyées à GitHub.

Le verrouillage de l’iPhone protège l’accès. Aucun mot de passe supplémentaire n’est ajouté dans l’application.
