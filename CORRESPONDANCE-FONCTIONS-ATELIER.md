# Fonctions et accès dans Atelier

Cette correspondance concerne le build `2026.15.2`. La refonte conserve les fonctions de l’archive corrigée ; les ajouts autorisés sont signalés. Aucun serveur ni compte n’est requis.

## Navigation et agenda

| Fonction | Accès dans Atelier |
|---|---|
| Ouvrir les rendez-vous du jour | Écran initial Agenda, vue Jour, date du jour |
| Jour / Semaine / Mois | Sélecteur en haut de l’agenda |
| Date précédente / suivante et retour au jour courant | Flèches, bande des jours et bouton Aujourd’hui ; commandes équivalentes en Semaine et Mois |
| Heures, durées, disponibilités, chevauchements | Grilles horaires Jour et Semaine ; les rendez-vous conservent leur durée visuelle |
| Programme d’un jour depuis le mois | Toucher le jour dans Mois ; actions Ajouter un RDV / Ajouter un événement |
| Recherche de rendez-vous | Loupe en haut de l’agenda |
| Recherche d’un créneau disponible | Créneau libre, au-dessus du planning ; recherche existante conservée |
| Nouvelle proposition adaptée à la prestation | Dans le formulaire RDV, « Trouver un créneau libre », aide facultative utilisant la durée choisie |
| Créer un rendez-vous normalement | Ajouter → Nouveau rendez-vous ; saisir cliente, prestation, date et heure |
| Création directement à une heure | Toucher une plage de la grille horaire |
| Modifier un rendez-vous | Toucher le rendez-vous dans les grilles, le programme du mois, la recherche ou les listes de suivi |
| Événements personnels | Ajouter → Événement personnel ; édition depuis les grilles ou le programme du mois |
| Événement bloquant ou informatif, journée entière et plusieurs jours | Choix conservés dans le formulaire d’événement |
| Prochain rendez-vous | Journée → Prochain rendez-vous ; cette information reste globale et porte sa date |
| Résumé du jour sélectionné | Journée → Résumé de la journée |
| Fin de journée | Journée → Fin de journée |
| Tournée et itinéraires | Journée → Ma tournée ; Waze reste aussi disponible depuis les adresses des rendez-vous et des clientes |
| Relances de paiement | À suivre → Relance paiement, puis liste des paiements à relancer |
| Rendez-vous à confirmer | À suivre → Confirmations |
| Journées non clôturées | À suivre → Journée non clôturée |
| Rappel de sauvegarde | À suivre → rappel ; raccourci Sauvegarder mes données dans Fichiers |
| Brouillons et reprise | Bande « Saisie en cours » près du planning, également accessible en Semaine et Mois |
| Mise à jour disponible | Bande dédiée ; les protections contre une perte de saisie sont maintenues |

« À suivre » affiche un compteur global. Changer la date du planning ne masque pas les obligations d’une autre journée. Mes tâches et Journée restent accessibles par deux commandes nommées au-dessus de la navigation inférieure. Aucun tableau de bord Aujourd’hui n’est créé.

## Rendez-vous et clientes

| Fonction | Accès dans Atelier |
|---|---|
| Sélectionner ou créer une cliente | Formulaire RDV → Cliente ; suggestions et choix explicite entre homonymes |
| Coordonnées et adresse | Formulaire RDV → Cliente → Modifier les coordonnées, ou fiche cliente |
| Prestation, durée, prix | Formulaire RDV → Prestation ; Ajuster permet de modifier durée et prix proposés |
| Suppléments | Formulaire RDV → Suppléments → Ajouter |
| Date, heure, statut | Formulaire RDV → Créneau ; la saisie reste libre |
| Avertissement de chevauchement | Contrôle lors de la saisie et de l’enregistrement ; possibilité existante d’enregistrer malgré l’avertissement conservée |
| Notes, paiement, prochain RDV et historique | Formulaire RDV → Plus d’options ; fonctions de paiement et d’historique accessibles en édition |
| À vérifier / À régler / Payé / Remboursé | Paiement du rendez-vous ; date réelle, relance et verrou des montants conservés |
| Prix absent ou zéro explicite | Champ Prix de base : vide et 0 restent deux valeurs distinctes |
| Recherche et filtres clientes | Onglet Clientes, recherche et menu Filtrer |
| Fiche et repère | Clientes → choisir une fiche ; coordonnées, repère, notes et statistiques |
| Historique complet | Fiche cliente → Voir tout l’historique lorsque plus de 12 rendez-vous |
| Reprendre un rendez-vous | Fiche cliente → Reprendre sur une ligne d’historique |
| Annulations tardives et paiements en attente | Filtres Clientes, statistiques et historique de la fiche |

La création ne dépend jamais de la présence d’un créneau libre. Les propositions ne modifient la date et l’heure qu’après sélection explicite. Les homonymes restent des fiches indépendantes ; aucune fusion automatique n’est introduite.

## Dépenses et Bilan

| Fonction | Accès dans Atelier |
|---|---|
| Ajouter une dépense | Ajouter → Ajouter une dépense |
| Catégorie, articles, fournisseur, date et montant | Formulaire Dépense |
| Catégories de dépenses | Gestion des catégories depuis le formulaire ; catégories historiques conservées |
| Consulter ou modifier une dépense | Bilan → Dépenses → période et détail de la dépense |
| Dupliquer une dépense — ajout | Ouvrir une dépense → Dupliquer ; un nouveau formulaire est préparé à la date du jour, à vérifier avant validation |
| Périodes Jour / Semaine / Mois / Année | Onglet Bilan → sélecteur de période et flèches |
| Prestations / Encaissements / Dépenses | Onglet Bilan → sélecteur de rubrique |
| Classements et détails | Rubrique Prestations → ordre par nombre ou montant ; toucher une ligne |
| Export CSV | Bilan → Exporter le bilan ; correspond à la période et à la rubrique affichées |

Les prestations suivent les rendez-vous, les encaissements suivent les paiements et les remboursements leur propre date. Le net encaissé signifie brut moins remboursements. Les dépenses restent une rubrique distincte. Aucun justificatif ni pièce jointe n’est ajouté.

| Version et schéma | Réglages → À propos |

## Ajouts utiles

| Ajout | Accès et comportement |
|---|---|
| To Do personnelle | Mes tâches, ou Ajouter → Nouvelle tâche ; titre, échéance facultative, modification, terminer, remettre à faire et supprimer |
| Tâches terminées | Mes tâches → Terminées |
| Protection de la saisie d’une tâche | Brouillon et avertissement de modifications non enregistrées |
| Conservation des tâches | IndexedDB, copies automatiques et sauvegardes JSON ; migration v15 → v16 avec liste initialement vide |
| Discrétion | Icône en haut de l’agenda ; masque les montants des écrans de consultation. Pour ouvrir un formulaire financier, l’application propose de quitter ce mode |

Les exports et sauvegardes contiennent toujours les montants réels. Le mode discrétion protège seulement l’affichage ; il ne chiffre pas les données. Aucun suivi de matériel ni nouvelle fonction de relation cliente n’est ajouté.

## Limite de cette vérification

La correspondance est vérifiée dans le code livré et par les tests structurels et comportementaux décrits dans `TESTS-ATELIER.md`. Le confort tactile, le clavier, VoiceOver et le rendu exact doivent encore être vérifiés sur un vrai iPhone.
